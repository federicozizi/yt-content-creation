Cos'è questa integrazione

Claude Code e Antigravity sono entrambi "agenti AI che lavorano per te", ma vivono in posti opposti e fanno cose opposte. Metterli in coppia non significa farli litigare: significa dare a ciascuno il pezzo di lavoro che sa fare meglio.

Antigravity è una piattaforma cloud di Google. Apri il browser, dai un'istruzione, e lui spawna agenti AI in parallelo che lavorano ognuno nel suo ambiente isolato. Restituisce artefatti verificabili: file, screenshot, preview. Tu li guardi e decidi.
Claude Code è il terminale sul tuo PC. Vede i tuoi file veri, esegue comandi sulla tua macchina, modifica il tuo repo. Niente sandbox: sei tu, lui e i tuoi file.

L'integrazione non è una API magica. È una divisione di lavoro: Antigravity esplora opzioni in parallelo (cosa che richiederebbe ore in seriale), Claude Code prende il risultato che hai scelto e lo cuce dentro al tuo progetto reale.

Cosa faremo oggi

Per mostrare il pattern useremo un caso concreto: rifare la home page di un sito esistente. Hai un index.html, vuoi 3 versioni grafiche diverse, vuoi vederle tutte prima di scegliere, e poi vuoi che la vincente venga integrata pulita nel tuo repo.

Il workflow in 3 mosse:

TU │ ├─→ ANTIGRAVITY (cloud) │ ├─ Agente 1 → home stile "corporate" ┐ │ ├─ Agente 2 → home stile "amichevole" │ in parallelo, ~3 min │ └─ Agente 3 → home stile "aggressive" ┘ │ ↓ │ 3 artefatti HTML + preview a schermo │ ↓ │ Scegli la migliore, scarica l'HTML │ └─→ CLAUDE CODE (locale) "prendi questa HTML, integrala nel mio repo, mantieni i link esistenti, aggiorna i meta tag" ↓ index.html aggiornato + commit pulito

Tempo totale, tutto compreso: 5-7 minuti. Senza il workflow combinato, le tre varianti le faresti in seriale con un solo agente — minimo 20-30 minuti, più tu che alterni tra tab e perdi il filo.

Come funziona il sistema

Tre "pezzi" lavorano in sequenza:

  1. Antigravity Manager — l'interfaccia browser dove tu dai 1 prompt e lui lo distribuisce a N agenti. Vedi tutti gli agenti in una dashboard, in tempo reale.
  2. Artefatti — i file/preview che ogni agente produce. Non sono solo testo: Antigravity ti fa vedere il rendering, gli screenshot, i diff. Tu approvi.
  3. Claude Code — il finale a casa tua. Riceve l'artefatto vincente come input, e fa l'integrazione fine: rispetta la struttura esistente, riusa i tuoi componenti, scrive il commit message.
Regola di divisione: tutto quello che richiede esplorare (varianti, alternative, "fammi vedere come potrebbe essere") → Antigravity. Tutto quello che richiede tagliare e cucire nel tuo progetto reale → Claude Code.

Setup iniziale

Tre cose ti servono, una sola la dobbiamo configurare oggi:

  • Un account Google con accesso ad Antigravity (antigravity.google.com) — l'accesso è gratuito ma in alcuni periodi richiede waitlist.
  • Claude Code installato sul tuo PC (lo usi già, quindi è fatto).
  • Una cartella di progetto sul tuo PC con dentro almeno un index.html da rifare. Se non ce l'hai, nei materiali trovi un mini-sito demo.

Per il setup operativo: lancia claude dentro la cartella materiali/ e digli "esegui il setup leggendo CLAUDE.md". Fa tutto da solo in 1 minuto.

Step 1 — Drafting parallelo su Antigravity

Il primo step è quello che da soli non potreste fare velocemente: generare 3 alternative contemporaneamente, in 3 ambienti isolati, ognuno con il suo prompt.

Perché Antigravity e non Claude Code per questa parte: Claude Code è seriale. Un'istanza alla volta, sul tuo PC. Antigravity ti spawna 3 agenti in cloud con un click. Tre teste pensano in parallelo, tu aspetti una volta sola.

Nel nostro caso

Vogliamo 3 stili: corporate (formale, monocromatico, focus su trust), amichevole (colori caldi, immagini di persone, tono conversazionale), aggressive (claim grossi, urgenza, CTA dominante).

Cosa fare

  1. Apri Antigravity e crea un nuovo workspace
    Vai su antigravity.google.com, login Google, "New workspace". Dagli un nome riconoscibile (es. "homepage-refresh").
  2. Spawna 3 sessioni con lo stesso file di partenza
    Carica il tuo index.html attuale nel workspace. Apri 3 sessioni agente, una per variante. Ognuna parte dallo stesso file ma con un prompt diverso.
  3. Incolla il prompt di drafting in ogni sessione
    Il prompt è pronto in materiali/prompts/antigravity-parallel-draft.md: copialo, cambia solo la parola "STILE" coi tre stili (corporate / amichevole / aggressive), e mandalo.
  4. Lascia girare e fai altro
    Antigravity ti notifica quando ogni agente ha finito. Mediamente 2-4 minuti per agente, tutti in parallelo. Tu nel frattempo prendi un caffè o continui altro.

Il prompt completo è in materiali/prompts/antigravity-parallel-draft.md.

Step 2 — Scegli l'artefatto giusto

Quando i 3 agenti hanno finito, Antigravity ti dà 3 cose per ognuno: il file HTML prodotto, una preview renderizzata, e uno screenshot.

Il valore degli "Artefatti": non devi leggere 300 righe di codice per capire se la home è bella. Antigravity te la mostra renderizzata. Tu giudichi con l'occhio, in 30 secondi a versione.

Nel nostro caso

Apri le 3 preview affiancate. La corporate è troppo fredda, la aggressive è urlata, l'amichevole ha il tono giusto ma il claim è debole. Scegli l'amichevole e prendi nota mentale di cosa migliorare al claim — quel feedback lo darai a Claude Code in locale.

Cosa fare

  1. Apri le 3 preview
    In Antigravity, ogni sessione finita ha un bottone "Preview" che renderizza l'HTML in un mini-browser dentro il workspace.
  2. Scegli quella che funziona meglio
    Non quella perfetta, quella più vicina. Se tutte hanno problemi, prendi la migliore: la lavorerai con Claude Code dopo.
  3. Scarica l'HTML come artefatto
    Click destro → "Download artifact" → salvalo come landing-vincitrice.html nella cartella materiali del progetto.

Step 3 — Claude Code la integra in locale

L'HTML di Antigravity è bello ma è scollegato dal tuo progetto reale: usa link inventati, non ha i tuoi meta tag, magari ha rinominato file che esistono già nel tuo repo. Qui entra Claude Code.

Perché Claude Code e non Antigravity per questa parte: Antigravity lavora in sandbox — non ha accesso al tuo filesystem reale, ai tuoi link interni, alla tua struttura di cartelle. Claude Code sì. Lui legge tutto il repo, capisce cosa deve mantenere, e fa un commit pulito.

Nel nostro caso

Apri il terminale dentro la cartella del tuo sito. Lanci claude e gli dai il prompt di integrazione (pronto nei materiali). Lui legge la home vecchia, legge la nuova, fonde le parti grafiche della nuova coi link/meta della vecchia, e ti propone il diff prima di salvare.

Cosa fare

  1. Apri il terminale nella cartella del tuo sito
    cd ~/mio-sito && claude
  2. Incolla il prompt di integrazione
    Il prompt è in materiali/prompts/claude-code-handoff.md: gli dice di leggere landing-vincitrice.html, fonderla con l'index.html esistente preservando link/meta/asset, e mostrarti il diff.
  3. Approva il diff e fagli fare il commit
    Claude Code ti mostra cosa cambia, riga per riga. Se sei d'accordo, dici "vai, committa con un messaggio sensato". Se no, gli chiedi correzioni mirate.
    index.html aggiornato. Commit: "feat: refresh home con stile amichevole — variante scelta da Antigravity"
  4. (Opzionale) Cancella i file temporanei
    I 3 artefatti di Antigravity non ti servono più nel repo. Chiedi a Claude di spostarli in una sottocartella _archivio/ o di cancellarli.

Il prompt di handoff è in materiali/prompts/claude-code-handoff.md.

Oltre la landing page: dove vale lo stesso pattern

Lo schema "Antigravity esplora in parallelo → tu scegli → Claude Code integra in locale" vale ogni volta che hai un problema dove (a) ci sono più direzioni plausibili da provare, (b) la scelta finale richiede un occhio umano, (c) l'integrazione tocca il tuo progetto reale.

Email di vendita in 3 toni Antigravity scrive 3 versioni della stessa email (curiosità / scarsità / autorevolezza). Tu scegli. Claude Code la salva nel tuo CRM o sistema di email marketing locale.
Proposta cliente in 3 angoli Antigravity prepara 3 strutture di proposta (focus prezzo / focus ROI / focus rischio). Tu scegli quella che funziona meglio per quel cliente. Claude Code la integra nel tuo template aziendale, sostituisce loghi, dati, allegati.
Audit competitor in parallelo Antigravity spawna 5 agenti, uno per competitor. Ognuno fa scraping, screenshot, analisi pricing. Tu rivedi i 5 report. Claude Code li consolida in un unico documento Markdown nel tuo Drive o Notion locale.
Documentazione di prodotto in 3 voci Antigravity scrive 3 versioni dello stesso help article (formale / discorsivo / da power-user). Tu scegli. Claude Code la pubblica sul tuo sito statico e aggiorna il sitemap.
Test di un'idea di prodotto Antigravity ti spawna 3 mini-landing per testare 3 angoli di posizionamento diversi sullo stesso prodotto. Tu fai un sondaggio rapido in community. Claude Code prende la vincitrice, la mette sul tuo dominio, attacca il pixel di tracciamento.

Riepilogo

Hai imparato un pattern, non un tool. Il pattern è:

  • Antigravity serve quando ti serve esplorare in parallelo: 3 versioni invece di 1, 5 angoli invece di 1, in cloud, senza scaldare il PC.
  • Claude Code serve quando ti serve chiudere il cerchio nel tuo progetto reale: leggere file veri, rispettare struttura esistente, fare commit.
  • Il ponte tra i due è l'artefatto: tu scarichi il file vincente da Antigravity, lo passi a Claude Code come input.
  • Niente API custom, niente integrazione magica: è un workflow umano-in-mezzo. Tu sei il giudice tra cloud e locale.
