# Fallback: usare cron Linux/Mac al posto di Claude Routines
#
# Apri il tuo crontab con: crontab -e
# Aggiungi UNA delle righe sotto.
# Sostituisci /path/to/materiali col path reale della tua cartella.

# === Ogni giorno alle 8:00 ===
0 8 * * * cd /path/to/materiali && /usr/local/bin/claude --print "$(cat prompts/newsletter-daily.md)" >> /tmp/newsletter.log 2>&1

# === Solo nei giorni lavorativi (lun-ven) alle 8:00 ===
0 8 * * 1-5 cd /path/to/materiali && /usr/local/bin/claude --print "$(cat prompts/newsletter-daily.md)" >> /tmp/newsletter.log 2>&1

# === Ogni 3 ore (per fonti molto attive) ===
0 */3 * * * cd /path/to/materiali && /usr/local/bin/claude --print "$(cat prompts/newsletter-daily.md)" >> /tmp/newsletter.log 2>&1


# === SU WINDOWS (Task Scheduler) ===
# Apri "Utilità di pianificazione" → Crea attività → Trigger giornaliero ore 8:00
# Azione: "Avvia programma"
#   Programma: powershell.exe
#   Argomenti: -Command "cd 'C:\path\to\materiali'; claude --print (Get-Content prompts\newsletter-daily.md -Raw)"
#   (assicurati che claude.exe sia nel PATH)


# === NOTE ===
# - Verifica il path di claude con: which claude (Mac/Linux) o where claude (Windows)
# - Il log in /tmp/newsletter.log ti permette di vedere cosa è successo se la run fallisce
# - Su Mac, dare a cron i permessi di "Full Disk Access" in Privacy & Security
