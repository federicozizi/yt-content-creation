Claude Code + Antigravity: how to use them together

Two AIs on the same project: one in the cloud that explores in parallel, one on your machine that closes the loop. 7 minutes to learn how they split the job.

📌 Who this video is for

You already use Claude Code. You've heard of Antigravity (Google's new "agent IDE" in the cloud) and you want to know whether it's worth combining them — and how.

You don't need to be a developer. Both tools have a visual interface; the integration is two copy-paste prompts plus your judgment. The example we'll use is refreshing a landing page, but the pattern works for anything made of files.

What this integration is

Claude Code and Antigravity are both "AI agents working for you", but they live in opposite places and do opposite things. Pairing them isn't about making them fight: it's about giving each one the piece of work they're best at.

Antigravity is a cloud platform from Google. Open the browser, give it an instruction, and it spawns AI agents in parallel — each one working in its own isolated environment. It returns verifiable artifacts: files, screenshots, previews. You look at them and decide.
Claude Code is the terminal on your PC. It sees your real files, runs commands on your machine, edits your repo. No sandbox: it's you, it, and your files.

The integration isn't a magic API. It's a division of labor: Antigravity explores options in parallel (something that would take hours sequentially), Claude Code takes the result you've chosen and stitches it cleanly into your real project.

What we'll do today

To make the pattern concrete we'll use one example: refresh the home page of an existing site. You have an index.html, you want 3 different visual versions, you want to see all of them before picking one, and then you want the winner integrated cleanly into your repo.

The workflow, in 3 moves:

YOU │ ├─→ ANTIGRAVITY (cloud) │ ├─ Agent 1 → home in "corporate" style ┐ │ ├─ Agent 2 → home in "friendly" style │ in parallel, ~3 min │ └─ Agent 3 → home in "aggressive" style ┘ │ ↓ │ 3 HTML artifacts + on-screen previews │ ↓ │ Pick the best, download the HTML │ └─→ CLAUDE CODE (local) "take this HTML, integrate it into my repo, keep the existing links, update the meta tags" ↓ updated index.html + clean commit

Total time, all in: 5-7 minutes. Without the combined workflow, you'd do the three variants sequentially with a single agent — at least 20-30 minutes, plus you switching between tabs and losing focus.

How the system works

Three pieces work in sequence:

  1. Antigravity Manager — the browser interface where you give one prompt and it dispatches it to N agents. You see every agent on a dashboard, in real time.
  2. Artifacts — the files/previews each agent produces. Not just text: Antigravity shows you the rendering, the screenshots, the diffs. You approve.
  3. Claude Code — the final mile, on your machine. It receives the winning artifact as input and does the fine integration: respects the existing structure, reuses your components, writes the commit message.
Division rule: anything that needs exploring (variants, alternatives, "show me what it could look like") → Antigravity. Anything that needs cutting and stitching inside your real project → Claude Code.

Initial setup

Three things you need — only one we have to configure today:

  • A Google account with access to Antigravity (antigravity.google.com) — access is free but during some periods requires a waitlist.
  • Claude Code installed on your PC (you already use it, so done).
  • A project folder on your PC with at least an index.html you want to refresh. If you don't have one, the materials include a minimal demo site.

For the operational setup: run claude inside the materiali/ folder and tell it "run the setup by reading CLAUDE.md". It handles everything in one minute.

Step 1 — Parallel drafting on Antigravity

The first step is the one you couldn't do quickly on your own: generate 3 alternatives at the same time, in 3 isolated environments, each with its own prompt.

Why Antigravity and not Claude Code for this part: Claude Code is sequential. One instance at a time, on your PC. Antigravity spawns 3 agents in the cloud with a click. Three heads think in parallel, you wait only once.

In our case

We want 3 styles: corporate (formal, monochrome, trust-focused), friendly (warm colors, people imagery, conversational tone), aggressive (big claims, urgency, dominant CTA).

What to do

  1. Open Antigravity and create a new workspace
    Go to antigravity.google.com, sign in with Google, "New workspace". Give it a recognizable name (e.g. "homepage-refresh").
  2. Spawn 3 sessions with the same starting file
    Upload your current index.html to the workspace. Open 3 agent sessions, one per variant. Each starts from the same file but with a different prompt.
  3. Paste the drafting prompt in each session
    The prompt is ready in materiali/prompts/antigravity-parallel-draft.md: copy it, change only the word "STYLE" to one of the three styles (corporate / friendly / aggressive), send it.
  4. Let it run, do something else
    Antigravity notifies you when each agent is done. Roughly 2-4 minutes per agent, all in parallel. In the meantime you get a coffee or move to something else.

The full prompt is in materiali/prompts/antigravity-parallel-draft.md.

Step 2 — Pick the right artifact

When the 3 agents are done, Antigravity gives you 3 things for each: the HTML file produced, a rendered preview, and a screenshot.

The value of "Artifacts": you don't have to read 300 lines of code to know whether the home looks good. Antigravity shows it to you rendered. You judge with your eyes, 30 seconds per version.

In our case

Open the 3 previews side by side. The corporate is too cold, the aggressive is shouty, the friendly has the right tone but the claim is weak. Pick the friendly and make a mental note of what to fix on the claim — you'll pass that feedback to Claude Code locally.

What to do

  1. Open the 3 previews
    In Antigravity, every finished session has a "Preview" button that renders the HTML in a mini-browser inside the workspace.
  2. Pick the one that works best
    Not the perfect one, the closest one. If they all have issues, take the best: you'll polish it with Claude Code later.
  3. Download the HTML as an artifact
    Right click → "Download artifact" → save it as landing-winner.html in your project's materials folder.

Step 3 — Claude Code integrates it locally

The HTML from Antigravity is nice but it's disconnected from your real project: it uses made-up links, doesn't have your meta tags, may have renamed files that already exist in your repo. This is where Claude Code comes in.

Why Claude Code and not Antigravity for this part: Antigravity works in a sandbox — it has no access to your real filesystem, your internal links, your folder structure. Claude Code does. It reads your whole repo, understands what to preserve, and makes a clean commit.

In our case

Open the terminal inside your site's folder. Run claude and give it the integration prompt (ready in the materials). It reads the old home, reads the new one, fuses the visual parts of the new with the links/meta of the old, and shows you the diff before saving.

What to do

  1. Open the terminal in your site's folder
    cd ~/my-site && claude
  2. Paste the integration prompt
    The prompt is in materiali/prompts/claude-code-handoff.md: it tells Claude to read landing-winner.html, fuse it with the existing index.html preserving links/meta/assets, and show you the diff.
  3. Approve the diff and let it commit
    Claude Code shows you what changes, line by line. If you agree, say "go, commit with a sensible message". If not, ask for targeted fixes.
    index.html updated. Commit: "feat: refresh home with friendly style — variant picked from Antigravity"
  4. (Optional) Clean up the temporary files
    The 3 Antigravity artifacts aren't needed in the repo anymore. Ask Claude to move them to an _archive/ subfolder or delete them.

The handoff prompt is in materiali/prompts/claude-code-handoff.md.

Beyond the landing page: where the same pattern works

The schema "Antigravity explores in parallel → you choose → Claude Code integrates locally" works every time you have a problem where (a) there are multiple plausible directions to try, (b) the final choice needs a human eye, (c) the integration touches your real project.

Sales emails in 3 tones Antigravity writes 3 versions of the same email (curiosity / scarcity / authority). You pick. Claude Code saves it into your local CRM or email marketing system.
Client proposal from 3 angles Antigravity prepares 3 proposal structures (price-focused / ROI-focused / risk-focused). You pick the one that fits the client. Claude Code drops it into your company template, swaps logos, data, attachments.
Competitor audit in parallel Antigravity spawns 5 agents, one per competitor. Each does scraping, screenshots, pricing analysis. You review the 5 reports. Claude Code consolidates them into a single Markdown document in your local Drive or Notion.
Product documentation in 3 voices Antigravity writes 3 versions of the same help article (formal / conversational / power-user). You pick. Claude Code publishes it on your static site and updates the sitemap.
Product idea testing Antigravity spins up 3 mini-landing pages to test 3 different positioning angles for the same product. You run a quick poll in your community. Claude Code takes the winner, puts it on your domain, attaches the tracking pixel.

Recap

You've learned a pattern, not a tool. The pattern is:

  • Antigravity for when you need to explore in parallel: 3 versions instead of 1, 5 angles instead of 1, in the cloud, without overheating your PC.
  • Claude Code for when you need to close the loop inside your real project: real files, existing structure, your commits.
  • The bridge between the two is the artifact: download the winning file from Antigravity, hand it to Claude Code as input.
  • No custom API, no magic integration: it's a human-in-the-loop workflow. You're the judge between cloud and local.
