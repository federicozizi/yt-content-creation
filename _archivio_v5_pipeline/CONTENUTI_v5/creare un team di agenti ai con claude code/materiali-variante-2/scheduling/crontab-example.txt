# Esempio di riga crontab per schedulare team_agenti.py ogni mattina alle 7:00
# Modifica i path coi tuoi reali, poi aggiungi la riga eseguendo: crontab -e

0 7 * * * cd /Users/<tuo-utente>/competitor-intel-py && /Users/<tuo-utente>/competitor-intel-py/.venv/bin/python team_agenti.py >> cron.log 2>&1

# Spiegazione dei campi cron:
# 0 7 * * * = al minuto 0, ora 7, ogni giorno, ogni mese, ogni giorno della settimana
# cd /Users/.../competitor-intel-py = entra nella cartella del progetto
# /Users/.../.venv/bin/python = usa il Python del venv (importante!)
# team_agenti.py = esegui lo script
# >> cron.log 2>&1 = salva stdout + stderr nel file cron.log

# IMPORTANTE: il computer DEVE essere acceso alle 7:00 per cron locale.
